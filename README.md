# WhatsApp-style chat viewer

Open `index.html` in any modern browser, choose an exported WhatsApp `.txt` chat file or WhatsApp export `.zip`, then choose which participant's messages should appear on the right. It supports both Android exports (`date, time - Name: message`) and iPhone exports (`[date, time] Name: message`).

For ZIP exports, the reader finds the chat text automatically and displays referenced images, videos, audio, and documents directly from the archive. The archive is processed in your browser; media is never uploaded.

No server or installation is required; the selected file is processed locally in the browser.
